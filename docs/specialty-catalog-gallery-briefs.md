# Specialty catalog gallery completion briefs

The Preview catalog includes an original, inspected `hero.webp` for every specialty product. Do not substitute a reference thumbnail, stretch a master image, or use an image from another configuration for the remaining views.

For each product below, create these matching-master views at **1448 × 1086** in this order:

1. `front-view.webp`
2. `side-angle.webp`
3. `rear-view.webp`
4. `representative-1.webp`
5. `representative-2.webp`
6. `door-detail.webp`
7. `interior-1.webp`

All images must retain the same master container color, height, size, door arrangement, condition, generic non-branded markings, and wear level as its finished hero. Use a seamless white studio setting and natural floor shadow unless the interior view requires a clean interior-only framing. Never add real owner identifiers, stock numbers, brand names, temperature values, voltage, certifications, warranties, or availability labels.
